# SheCanCode Advanced Frontend – Week 8: React Effects, Hooks & Rendering

Each day is a separate React 19 + Vite project with its own `package.json`.

| Folder | Topic | In-class activity | Answers |

| [day1](day1) | `useEffect`: side effects and the component lifecycle | Effects Lab | [ANSWERS.md](day1/ANSWERS.md) |

| [day3](day3) | Custom Hooks | Hooks Toolkit (8 hooks) | [HOOKS.md](day3/HOOKS.md) |

## Run a day

```bash
cd day1        # or day2 … day5
npm install
npm run dev
```

Open the link Vite prints, then the browser Console (F12) to see the logs.
