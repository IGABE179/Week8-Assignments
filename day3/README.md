# Hooks Toolkit

SheCanCode Advanced Frontend – Week 8, Day 3: custom Hooks.

Eight reusable Hooks in `src/hooks/` (one file each, named exports), each shown by a
working demo on one page:

`useToggle` · `useLocalStorage` · `useDebounce` · `useWindowSize` ·
`useOnlineStatus` · `useDocumentTitle` · `useKeyPress` · `useClickOutside`

```
src/
  hooks/        eight custom Hooks
  components/   one demo component per Hook
  App.jsx       the demo page
```

## Run it

```bash
npm install
npm run dev
```

Hook documentation and the Part A, E and F answers are in [HOOKS.md](HOOKS.md).
