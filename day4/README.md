# Refs Lab

SheCanCode Advanced Frontend – Week 8, Day 4: `useRef` and direct DOM access.

| Part | Demo | Ref used for |
|------|------|--------------|
| A | Local variable vs state vs ref counters | value that persists without rendering |
| B | Focus search | `focus()` |
| C | Scroll to details, Measure, Live width | `scrollIntoView()`, `getBoundingClientRect()`, `ResizeObserver` |
| D | Native dialog | `showModal()` / `method="dialog"` |
| E | Stopwatch (mount/unmount toggle) | interval ID |
| F | `MyInput` with React 19 `ref` prop | input inside a custom component |
| Ext. | Video, callback-ref list, previous-value logger | `play()`/`pause()`, `Map` of nodes, last value |

`public/videos/demo.mp4` is a short generated test-pattern clip, so there are no
copyright issues.

## Run it

```bash
npm install
npm run dev
```

Answers for Parts A, D, F and G are in [REFS.md](REFS.md).
